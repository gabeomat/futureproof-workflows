# Futureproof Workflows

Ready-to-install workflows for Claude Code, built by Gabriel Omat. A new one is added every week.

Each workflow takes one job off your plate. You install only the ones you want.

## Add the library (once)

In Claude Code, type:

```
/plugin marketplace add gabeomat/futureproof-workflows
```

This adds the library as a menu. Nothing installs yet.

## Install a workflow

Type `/plugin`, browse the workflows, and install the ones you want. Or install one by name:

```
/plugin install workflow-name@futureproof-workflows
```

To remove one later, open `/plugin` and uninstall it. Your other workflows stay as they are.

## Get new workflows

Open `/plugin` and update the library to see the latest workflows.
